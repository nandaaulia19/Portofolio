Website Portofolio Pribadi HTML · CSS

  • Membangun website portofolio pribadi menggunakan HTML5 dan CSS3 dengan struktur halaman yang rapi dan responsif.
  • Menerapkan konsep semantic HTML, flexbox/grid, serta styling warna dan tipografi secara mandiri.

Perancangan Basis Data MySQL

  • Merancang skema basis data relasional (ERD) untuk studi kasus tugas mata kuliah.
  • Menulis query dasar seperti SELECT, INSERT, UPDATE, dan JOIN antar tabel.

Desain UI/UX Aplikasi Mobile Figma

  • Membuat wireframe dan prototype interaktif untuk aplikasi sederhana menggunakan Figma.
  • Menerapkan dasar-dasar user-centered design dan konsistensi komponen antarmuka.

Eksplorasi Basis Data NoSQL MongoDB

  • Mempelajari konsep basis data non-relasional berbasis dokumen (document-based database).
  • Melakukan operasi CRUD (Create, Read, Update, Delete) sederhana pada MongoDB.
